# dsh-webui-enhanced (DeepSeek Harness 增强 WebUI 插件)

> 🚀 **DeepSeek Harness 官方 WebUI 交互增强插件（独立增量插件）**  
> 提供 Agent 思考与多步工具调用实时平铺/完成后一句话折叠总结、输入框 `+` 号菜单顶部多平台文件与图片上传卡片。

---

## 🌟 核心特性

### 1. 思考与多步工具：实时平铺 + 结算折叠总结
- **运行中平铺展示**：当 Agent 正在深度思考或连续调用多步工具（如搜索、代码执行、读写文件）时，整个过程保持平铺展开状态，便于用户实时追踪每一步进度与执行细节。
- **完成后自动折叠**：当该轮次执行完毕、等待用户下一次输入时，自动将提问与最终回答之间的所有中间过程收起为单行摘要栏：
  > **思考 14 次，调用工具 99 次，共用时 10m33s (输入 3.3M · 输出 3.3K · 缓存 3.2M · 命中率 98%)**
- **一键展开/收起**：点击摘要栏可随时平滑切换展开全部细节或重新折叠。
- **Token 消耗与命中率**：实时聚合该轮次输入、输出、前缀缓存 Tokens 及命中率百分比；可在设置中自由选择是否展示 Token 指标。

### 2. 输入框加号（`+`）菜单：跨平台图片与文件上传
- **专属顶部卡片**：点击输入框左侧加号（`+`）按钮时，在弹出的常用指令菜单顶部呈现两枚专属快捷卡片：
  - **上传图片**：支持 JPG、PNG、WEBP 等常见图像，移动端支持直接调起相机/相册；
  - **上传文件**：支持 PDF、代码、音视频、文档等任意格式。
- **完美防重叠**：卡片位于菜单顶部，下方以水平分隔线与官方 `/` 指令列表自然区隔，彻底杜绝任何文字或按钮重叠。
- **智能分流管道**：
  - 图片与音视频文件：直接接入 DSH 会话附件管道进行多模态传输；
  - 文本与代码文件：自动格式化为 Markdown 代码块注入输入框。

---

## 🛠️ 架构与集成机制

- **100% 独立增量设计**：不覆盖、不篡改官方任何核心包源码，完全通过 Cordis 微内核的标准插槽（`conversation.input.overlay` 等）与 DOM 装饰器接入。
- **防崩溃与零入侵**：完全规避 React 内部 Hook 条件调用（React #310）陷阱，在历史记录拉取（“加载更早”）及右侧导航轨（Rail）快速跳转时稳定不白屏。
